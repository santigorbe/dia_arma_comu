# Fuentes de fallback

`TeXGyreChorus-MediumItalic.otf` proviene del proyecto TeX Gyre y se distribuye bajo la GUST Font License.

Se incluye como alternativa libre para el texto que la plantilla declara como `TeXGyreChorus` y `Corsiva`. La plantilla original no contiene las fuentes incrustadas; para una reproducción tipográfica exacta hay que instalar las fuentes originales en el servidor.
